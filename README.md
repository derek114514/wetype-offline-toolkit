# 微信输入法离线工具箱

一个第三方小工具，对你**已经安装**的微信输入法做三件可逆的本地操作。
打开后用图形界面逐项选择：

1. **彻底断网** —— 为微信输入法的程序添加防火墙出站/入站阻止规则，并在系统 hosts 中屏蔽其服务器域名。云候选、同步、更新等联网功能随之失效。
2. **去除输入审查** —— 对本机 `libwxhld.dll` 打一个可逆的小补丁（6 字节），让引擎跳过敏感词拦截。打补丁前自动完整备份，可随时「还原」。按字节特征匹配，版本不符会拒绝修改。
3. **离线语音输入** —— 下载开源的 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 中文模型（大小自选），启用后在后台运行，按住 **F9** 说话，识别结果粘贴到当前窗口。它独立运行，不依赖微信输入法的语音按钮。

## 重要说明

- **本工具不包含、也不分发微信输入法的任何文件。** 它只修改你机器上已经装好的那一份。使用前请先自行安装官方微信输入法。
- **需要管理员权限**（防火墙、hosts、修改 Program Files 都要求）。双击 exe 会自动请求提权。
- 三项操作都可撤销：断网可「撤销」，审查可「还原」，语音可「停用」。
- 去审查的补丁只针对已验证的 `libwxhld.dll` 版本；换版本后需要重新适配，工具会在无法识别时拒绝修改以免损坏文件。

## 运行

直接运行源码：

```bash
python toolkit.py
```

打包成单个 exe（双击即用、无需装 Python）：

```bash
pip install pyinstaller -r requirements.txt
build.bat
```

生成的 exe 在 `dist\` 目录。断网与去审查不需要任何第三方库，只有离线语音需要 `requirements.txt` 里的依赖。
